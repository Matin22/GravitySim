GravitySim is a physics simulation project that models gravitational interactions between objects. It is designed for educational purposes and experimentation with gravity-based systems.

## Features

- Simulates gravitational forces between multiple bodies
- Visualizes object trajectories and interactions
- Configurable simulation parameters

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/GravitySim.git
   ```
2. Navigate into directory:
   ```bash
   cd GravitySim
   ```
3. Run the simulation:
   ```bash
   make run
   ```

## Usage

- Adjust simulation parameters in the configuration file or via command-line arguments.
- View simulation results in the provided visualization window.
